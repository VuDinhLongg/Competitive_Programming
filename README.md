## 📖 About This Repository

Xin chào, mình là **Vũ Đình Long** — `LonggVuz`, sinh viên **PTIT** và là một người yêu thích lập trình thi đấu.

Repository này lưu lại hành trình học tập, luyện tập và chinh phục các bài toán thuật toán của mình trên nhiều nền tảng. Mỗi lời giải không chỉ là một lần **Accepted**, mà còn là dấu mốc của quá trình tư duy, sửa sai và tiến bộ từng ngày.

> **The goal is not only to get AC, but to understand why the solution is correct.**

### Repository tập trung vào

- Các lời giải đã được chấp nhận trên những nền tảng lập trình thi đấu.
- Bài tập **Cấu trúc dữ liệu và Giải thuật** tại PTIT.
- Các vòng luyện tập, vòng loại và vòng chung kết **ICPC PTIT**.
- Những kỹ thuật, mẫu code và ý tưởng có thể tái sử dụng.
- Việc rèn luyện tư duy tối ưu về độ phức tạp, bộ nhớ và cách triển khai.

## 🚀 Getting Started

Clone repository:

```bash
git clone -b LonggVuz https://github.com/VuDinhLongg/Competitive-Programming.git
cd Competitive-Programming
```

Biên dịch một lời giải C++:

```bash
g++ -std=c++17 -O2 -pipe solution.cpp -o solution
./solution
```

Trên Windows:

```powershell
g++ -std=c++17 -O2 -pipe solution.cpp -o solution.exe
.\solution.exe
```
